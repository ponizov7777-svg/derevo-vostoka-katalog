# Дерево Востока

Каталог деревянных сувениров: лазерная гравировка и ЧПУ.

## Локальный просмотр

Откройте `index.html` в браузере или поднимите простой сервер:

```bash
python -m http.server 8080
```

Сайт: http://127.0.0.1:8080/
